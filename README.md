# Databricks Python SDK Playground

A hands-on learning repository for the Databricks Python SDK.

## What you'll learn

- Authenticate using Databricks CLI
- Connect to a Databricks Workspace
- List Unity Catalog objects
- List Jobs
- Deploy notebooks using the SDK
- Create Jobs programmatically
- Trigger Jobs
- Monitor Job executions

## Repository Structure

examples/
- Learn individual SDK APIs

use_cases/
- End-to-end automation workflows

docs/
- Short notes for each example
